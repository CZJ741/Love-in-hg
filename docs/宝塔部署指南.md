# Love-in-hg 宝塔面板部署指南

## 项目概况

| 项目 | 信息 |
|------|------|
| 后端框架 | Flask 3.1.0 + Flask-SQLAlchemy 3.1.1 + Flask-CORS 5.0.1 |
| 数据库 | MySQL 8.0 (love_hg) |
| WSGI 服务器 | Gunicorn 23.0.0 |
| Python 版本 | 3.10 (宝塔 Python 项目管理器推荐) |
| 端口 | 5000 (Gunicorn) → Nginx 反代 80/443 |
| 入口文件 | `backend/app.py` (create_app 工厂函数) |

---

## 一、宝塔面板环境安装

### 1.1 安装宝塔面板

如果你的服务器还没有安装宝塔面板，SSH 登录服务器后执行：

```bash
# CentOS/RedHat
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec

# Ubuntu/Debian
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

安装完成后会显示面板地址、用户名和密码，**请妥善保存**。

### 1.2 安装必要软件

登录宝塔面板后，进入 **软件商店**，安装以下软件：

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| **Nginx** | 1.20+ | 反向代理，提供 HTTPS 对外服务 |
| **MySQL** | 8.0 (或 5.7+) | 数据库 |
| **Python 项目管理器** | 最新版 | 管理 Python 虚拟环境和项目 |

> **注意**: 不需要安装 PHP，本项目纯 Python 后端。

## 四、配置环境变量 (.env)

在服务器 `backend/` 目录下创建 `.env` 文件：

```ini
# MySQL 连接配置
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=love_hg              # 你创建的数据库用户名 (或 root)
MYSQL_PASSWORD=your_db_password # 你的数据库密码
MYSQL_DB=love_hg

# 种子数据导入密码
INIT_DATA_PASSWORD=admin123
```

> **安全提示**: 不要将 `.env` 文件提交到 Git，确保 `.gitignore` 中包含 `.env`。

## 五、Python 项目管理器配置

### 5.1 创建 Python 项目

宝塔面板 → **Python 项目管理器** → **添加项目**：

| 字段 | 配置值 |
|------|--------|
| 项目名称 | `love_hg` |
| Python 版本 | 3.10 |
| 框架 | Flask |
| 启动方式 | Gunicorn |
| 项目路径 | `/www/wwwroot/Love-in-hg/backend` |
| 启动文件 | `app.py` |
| 端口 | `5000` |
| 启动命令 | 见下方 |
| 安装依赖 | 勾选 "安装依赖" |

### 5.2 Gunicorn 启动命令

宝塔 Python 项目管理器中，启动命令填写：

```bash
gunicorn --workers 4 --bind 127.0.0.1:5000 --timeout 120 --access-logfile /www/wwwlogs/love_hg_access.log --error-logfile /www/wwwlogs/love_hg_error.log "app:create_app"
```

参数说明：
| 参数 | 值 | 说明 |
|------|-----|------|
| `--workers` | 4 | worker 进程数 (建议 CPU 核数 × 2 + 1) |
| `--bind` | 127.0.0.1:5000 | 只监听本地，由 Nginx 反代 |
| `--timeout` | 120 | 请求超时秒数 |
| `app:create_app` | — | 模块名:工厂函数名 |

### 5.3 安装依赖

如果宝塔项目管理器没有自动安装依赖，SSH 手动安装：

```bash
# 进入项目目录
cd /www/wwwroot/Love-in-hg/backend

# 激活宝塔创建的虚拟环境 (路径根据实际面板显示为准)
source /www/server/pyporject_evn/love_hg_venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 验证安装
python -c "from app import create_app; print('OK')"
```

### 5.4 手动测试启动

```bash
cd /www/wwwroot/Love-in-hg/backend
source /www/server/pyporject_evn/love_hg_venv/bin/activate
gunicorn --workers 2 --bind 127.0.0.1:5000 "app:create_app"
```

测试是否正常：
```bash
curl http://127.0.0.1:5000/
# 应返回: {"code":0,"msg":"Love-in-hg backend is running",...}

curl http://127.0.0.1:5000/ping
# 应返回: {"code":0,"msg":"pong"}
```

## 六、Nginx 反向代理配置

### 6.1 添加站点

宝塔面板 → **网站** → **添加站点**：

| 字段 | 值 |
|------|-----|
| 域名 | `api.your-domain.com`（你的域名） |
| 根目录 | `/www/wwwroot/Love-in-hg` |
| PHP 版本 | 纯静态 |
| 数据库 | 不创建 |

### 6.2 配置 SSL 证书

**重要**: 微信小程序要求后端接口必须是 HTTPS，因此必须配置 SSL。

宝塔面板 → 网站 → 找到你的站点 → **SSL** → **Let's Encrypt** → 申请免费证书。

申请成功后开启 **强制 HTTPS**。

> **前提**: 域名必须已备案（国内服务器）或使用海外服务器。

### 6.3 配置 Nginx 反向代理

宝塔面板 → 网站 → 你的站点 → **设置** → **配置文件**，在 `server` 块内添加以下内容：

```nginx
server {
    listen 80;
    # 强制跳转 HTTPS
    server_name api.your-domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.your-domain.com;

    # SSL 证书 (宝塔会自动填入，以下为示例路径)
    ssl_certificate    /etc/letsencrypt/live/api.your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.your-domain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    # 反向代理到 Gunicorn
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_read_timeout 120s;
    }

    # 健康检查不记日志
    location = /ping {
        proxy_pass http://127.0.0.1:5000;
        access_log off;
    }
}
```

保存后重载 Nginx：
```bash
nginx -t && nginx -s reload
```

## 七、防火墙与端口

### 7.1 宝塔安全

宝塔面板 → **安全** → 放行端口：

| 端口 | 协议 | 用途 |
|------|------|------|
| 80 | TCP | HTTP (跳转 HTTPS) |
| 443 | TCP | HTTPS |
| 5000 | TCP | Gunicorn（可选，建议仅放行 127.0.0.1） |

> **建议**: 端口 5000 只允许 127.0.0.1 访问，对外只暴露 80/443。

### 7.2 云服务商安全组

如果你使用的是阿里云、腾讯云等，还需要在 **云控制台安全组** 中放行 80 和 443 端口。

## 十一、常见问题

### Q1: Gunicorn 启动失败

```bash
# 查看错误日志
cat /www/wwwlogs/love_hg_error.log

# 常见原因:
# 1. .env 文件路径不对 → 确保在 backend/ 目录下
# 2. MySQL 连不上 → 检查密码、端口、是否允许本地连接
# 3. 模块导入失败 → 检查虚拟环境是否激活，依赖是否装全
# 4. 端口被占用 → netstat -tlnp | grep 5000
```

### Q2: 502 Bad Gateway

Nginx 连不上 Gunicorn：
```bash
# 1. 检查 Gunicorn 是否在运行
ps aux | grep gunicorn

# 2. 检查 Nginx 配置中 proxy_pass 端口是否为 5000
# 3. 检查防火墙是否放行 5000 (或确认 Gunicorn 监听 127.0.0.1)
```

### Q3: 小程序请求失败（域名不合法）

1. 确认 BASE_URL 已改为 `https://api.your-domain.com/api`
2. 确认微信公众平台已添加域名到 request 合法域名
3. 确认 SSL 证书有效
4. 确认域名已备案（国内服务器）

### Q4: 数据库连接失败

```bash
# 测试 MySQL 连接
mysql -u love_hg -p -h 127.0.0.1 love_hg

# 检查 .env 配置是否正确
cat /www/wwwroot/Love-in-hg/backend/.env
```

### Q5: CORS 跨域问题

本项目已在 `app.py` 中全局开启 CORS（`origins: *`），理论上不会出现跨域问题。如果仍然报错：

```bash
# 检查 Nginx 是否正确转发 OPTIONS 请求
# Nginx 配置中确保没有手动拦截 OPTIONS
```

## 十二、项目文件修改建议（部署前）

部署前建议做以下调整：

### 12.1 关闭 debug 模式

`backend/app.py` 最后一行改为：
```python
if __name__ == '__main__':
    app = create_app()
    app.run(host='0.0.0.0', port=5000, debug=False)  # 生产环境关闭 debug
```

> **注意**: 使用 Gunicorn 启动时，`if __name__` 块不会执行，debug 默认为 False，这里只是保险措施。

### 12.2 清理硬编码密码

`backend/reset.py` 和 `backend/verify.py` 中有硬编码的数据库密码，部署时建议删除或改用环境变量读取：

```python
import os
password = os.getenv('MYSQL_PASSWORD', '')
```

### 12.3 确保 .env 不被 Git 追踪

`.gitignore` 中加入：
```
.env
__pycache__/
*.pyc
```
