## 四、使用说明

### 1. 启动后端服务
```bash
cd backend
python app.py
```
服务运行在 `http://127.0.0.1:5000`

### 2. 登录接口测试
```bash
curl -X POST http://127.0.0.1:5000/api/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"phone\":\"18103328533\"}"
```
返回 `isNewUser: false` 即为已注册用户，登录成功。

### 3. 浏览启事列表
```bash
curl "http://127.0.0.1:5000/api/notice/list?userId=1"
```
返回随机分配的启事列表（普通用户每月配额 10 条）。

### 4. 配额说明

| 会员类型 | 价格 | 配额 |
|----------|------|------|
| 普通用户 (free) | 免费 | 每月 10 条 |
| 会员 (member) | ¥99/年 | 每月 30 条 |
| 大会员 (vip) | ¥999/年 | 每天 30 条 |

> 当前所有测试账号均为 `free` 普通用户，每月可浏览 10 条。

### 5. 小程序前端配置
打开 `miniprogram/utils/api.js`，修改第 3 行：
```javascript
const BASE_URL = 'http://127.0.0.1:5000/api';
```
然后在微信开发者工具中打开 `miniprogram` 目录即可预览。

## 五、数据重置

如需重新导入数据：
```bash
# 1. 清空 notices 和 users 表
python -c "import pymysql; c=pymysql.connect(host='127.0.0.1',user='root',password='2248962829',database='love_hg').cursor(); c.execute('SET FOREIGN_KEY_CHECKS=0'); c.execute('TRUNCATE notices'); c.execute('TRUNCATE users'); c.execute('TRUNCATE notice_views'); c.execute('TRUNCATE membership_orders'); c.execute('SET FOREIGN_KEY_CHECKS=1'); c.connection.commit()"

# 2. 重新导入100条种子启事
curl -X POST http://127.0.0.1:5000/api/admin/initData -H "Content-Type: application/json" -d "{\"password\":\"admin123\"}"

# 3. 重新创建10个测试用户
python backend/create_test_users.py
```
